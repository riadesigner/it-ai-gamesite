# Indie Den — онлайн-магазин инди-игр

Инди-магазин игр: главная страница строится по концепции «магазин-тусовка», а не просто «полка с играми». Сейчас реализованы **шапка главной страницы** и **страница Лутс Маркет**.

## 🏠 Главная страница — `index.html`

Построена по `docs/homepage-plan.md`. На текущий момент реализован **раздел «Шапка-пульт»**:

- **Логотип** `IndieDen` с иконкой геймпада.
- **Поиск, понимающий фразы** — плейсхолдер показывает примеры: «уютный рогалик про сад», «кооп на вечер», «игра на 15 минут».
- **Переключатель настроения**:
  - `Спокойно / Хардкор` — переключение активного состояния (контент ещё не меняет).
- **Меню**: Каталог, Новинки, Скидки, Сообщество, **Лутс Маркет** (ссылка на `loots-market.html`).
- **Профиль** — кнопка с иконкой пользователя.

Ниже — заглушка с тегами будущих секций: **Сцена дня, Полка настроений, Три прилавка, Двор разработчиков, Демо-зал, Кооп-площадка, События, Ваш угол, Пульс**.

### План дальнейших секций (из `docs/homepage-plan.md`)

1. **Hero «Сцена дня»** — одна игра на 24 часа, трейлер, CTA, таймер.
2. **Полка настроений** — Уют, Хардкор, Кооп, 15 минут, Странное.
3. **Три прилавка** — Новое, Скрытые камни, Скоро.
4. **Двор разработчиков** — авторы, дневники, стримы.
5. **Демо-зал** — играть сразу, без установки.
6. **Кооп-площадка** — найти напарника.
7. **События** — джемы, фестивали, скидки.
8. **Ваш угол** — вишлист, рекомендации, бэклог.
9. **Пульс** — клипы, отзывы, скриншоты.
10. **Подвал** — ссылки, рассылка, соцсети.

## 🎲 Лутс Маркет — `loots-market.html`

Адаптивная таблица предметов лута в тёмной теме с зелёным акцентом. Кнопка-«домик» в шапке ведёт на главную (`index.html`).

### Возможности

- **Поиск по названию** — фильтрация в реальном времени.
- **Сортировка** по полям: `ID`, `Название`, `Тип`, `Редкость`, `Цена` — через выпадающий список, кнопку направления и клик по заголовку колонки.
- **Статистика** вверху: всего предметов, показано, суммарная стоимость.
- **Цветовая маркировка редкости**: Common, Uncommon, Rare, Epic, Legendary.
- **Иконки типов**: оружие, броня, аксессуары, расходники.

### Формат данных (`data/loot_items.json`)

```json
{
  "description": "20 универсальных предметов лута для RPG/фэнтези игры",
  "generated": "2026-09-15",
  "items": [
    {
      "id": 1,
      "name": "Ржавый кинжал",
      "type": "weapon",
      "rarity": "common",
      "slot": "main_hand",
      "stats": { "damage": 3, "speed": 1.5 },
      "value": 5,
      "description": "Старый зазубренный кинжал. Лучше, чем голыми руками."
    }
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | number | Уникальный идентификатор |
| `name` | string | Название предмета |
| `type` | string | `weapon`, `armor`, `accessory`, `consumable` |
| `rarity` | string | `common`, `uncommon`, `rare`, `epic`, `legendary` |
| `slot` | string | Слот экипировки (например `main_hand`, `chest`, `ring`, `potion`) |
| `stats` | object | Характеристики; значения `< 1` отображаются как проценты |
| `value` | number | Цена в монетах |
| `description` | string | Описание |

- **Тёмная тема** (единственная): фон `#0d1117`, поверхности `#161b22` / `#1c2333`.
- **Зелёный акцент**: `#22c55e`.
- **Иконки** — Font Awesome 6.5 (CDN).
- **Адаптив** — брейкпоинты: главная `1000px` / `760px`; таблица сворачивается на мобильных.

## 🚀 Запуск

Таблица Лутс Маркета загружает данные через `fetch('data/loot_items.json')`, поэтому страницу нужно открывать через HTTP-сервер, а не через `file://`.

```bash
# из корня проекта
python3 -m http.server 8000
```

Затем открой в браузере:

- `http://localhost:8000/index.html` — главная страница
- `http://localhost:8000/loots-market.html` — Лутс Маркет
