# AGENTS.md — инструкции для AI-агентов

## Правило дизайна сайта

**Прежде чем что-либо делать по дизайну сайта — сначала прочитай план главной страницы:**

- Файл: `docs/homepage-plan.md`

Это обязательное правило. Любые работы по дизайну (свёрстка, стили, структура, компоненты, разделы главной страницы) должны опираться на этот план. План — источник правды по структуре и наполнению сайта.

Порядок действий:
1. Прочитай `docs/homepage-plan.md`.
2. Сверь текущую реализацию с планом.
3. Только после этого вноси изменения по дизайну.

## Правило завершения задачи

**Как только запланированное дело полностью закончено — предложи закоммитить все изменения и запушить.**

- Сформулируй предложение так, чтобы пользователь мог просто ответить «да» или «нет».
- Предложение делается в конце ответа, после описания результата.
- Пользователь отвечает «да» → выполняешь `git add .`, `git commit` и `git push`.
- Пользователь отвечает «нет» → ничего не коммитишь и не пушишь.
